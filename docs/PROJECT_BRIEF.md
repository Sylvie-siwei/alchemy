# 中英文项目简介 / Project brief

## 中文简介

Alchemy 是一个 AI 原生需求演化工作空间原型，将原始反馈、提炼候选、人工决策与交付验证连接为可追溯的工作流。项目围绕五阶段生命周期、Raw / Unified 分层、有向来源关系、追加式演化记录和角色投影，探索如何让 AI 建议进入团队工作而不覆盖原始事实或绕过人工确认。公开版使用完全合成的数据和确定性 Mock 分析，不连接企业系统或真实模型，也未实现持久化、权限或 Agent 运行平台。

## English overview

Alchemy is an AI-native requirement workspace prototype that connects raw feedback, draft requirements, human decisions, and delivery validation in a traceable workflow. Its design combines a five-stage lifecycle, separate raw and unified signal data, directed lineage, appended evolution records, and role-based views. It explores how AI-generated suggestions can support team workflows while preserving source facts and human confirmation. The public edition uses synthetic data and deterministic Mock analysis. It does not call a live model or connect to enterprise systems, and it does not implement persistence, access control, or an agent runtime.

**English:** An AI-native requirement workspace prototype with human-confirmed drafts, source lineage, and role-based views. Synthetic data and Mock analysis only.

## 面向 AI Infra / Agent Infra 产品岗位的讨论点

- 产品边界：将原始事实、模型建议和正式决策分开，明确什么可以自动整理，什么需要确认。
- 系统思维：区分对象、处理阶段、观察视角、处理轮次与发布目标，避免用单一状态承载全部业务语义。
- 可追溯性：通过来源、变换、演化和决策记录解释对象如何形成。
- 交付证据：本地构建、类型检查、32 项测试及实际浏览器流程有验证记录；作者已确认主导产品构思、需求分析、系统设计、领域建模和开发；全部代码由 Codex 辅助生成与迭代，无其他人工贡献者；不宣称采用规模或商业效果。

这些讨论点来自当前原型的产品与工程结构，不代表已交付 GPU 调度、模型服务、Agent 执行或企业级基础设施。
